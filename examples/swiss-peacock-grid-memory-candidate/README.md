# Swiss Peacock Grid

Swiss System 子模板，用于 source-backed AI / 技术机制 / 产品架构类小红书图文。

## 定位

- Visual System: Swiss System
- Sub-template: Swiss Peacock Grid
- Palette: Peacock blue-green
- Best for: AI 机制解释、系统架构、技术文章精读、需要“可保存信息图”的长文拆解
- Avoid for: 情绪化种草、生活方式、纯教程截图、强营销产品发布

## 设计规则

- 保留 Swiss System 的严格网格、hairline 分隔线、直角模块、克制字体层级。
- 使用浅网格纸底，但不要把背景做成复古稿纸或完全照抄参考图。
- Peacock 色只用于重点字、关键模块、标签和少量强调，不要混入多套亮色。
- 复杂机制图必须用 GPT Image 生成信息型插图资产，再放进卡片；不要用 HTML/SVG 拼装抽象装饰图。
- 插图要有信息量：读者仅看图就能理解结构、权衡、流程或层级。
- 如果中文图中文字生成不稳定，可以使用英文标签，但卡片正文必须用中文解释。
- 封面更适合横向机制图，插图底色需要与卡片纸底一致，避免像硬塞进去的一块图。
- 每页必须有一个明确判断，而不只是中性列表。

## 页面结构建议

1. Cover: 大标题 + 横向信息图 + 一句可保存判断。
2. Diagnostic: 用 3-4 个模块解释基础误区。
3. Source Diagram: 关键机制图 + 读者场景解释。
4. System Layer: 层级、架构或组件关系图。
5. Matrix: 类型对比、适用场景、误区。
6. Process: 工作流、检索链路、闭环步骤。
7. Trade-offs: 关键权衡图，不做纯风险清单。
8. Checklist: 给读者可以保存执行的判断题或行动清单。

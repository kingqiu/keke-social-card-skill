# Swiss Peacock Grid Reference

这是 `Swiss Peacock Grid` 子模板的首个完整参考案例。

## 可复用点

- Peacock 蓝绿作为唯一强调色。
- 浅网格纸底 + Swiss System 严格排版。
- 封面使用横向信息图资产，底色与卡片纸底融合。
- 机制、层级、流程、权衡页优先使用 GPT Image 生成的信息型插图。
- 卡片正文用中文做解释，图中标签可在中文不稳定时保留英文。
- 页 2、5、8 使用结构化模块和判断句，承接信息图页面。

## 不应照搬

- 不要把文章特定文案、ByteByteGo 来源、AI Agent Memory 图像当作通用模板内容。
- 不要把信息图做成抽象装饰图；图必须承载结构、流程或权衡信息。
- 不要把 Peacock 色扩展成多色渐变或复杂配色。

## 推荐使用场景

- AI 机制解释
- 技术文章精读
- 系统架构拆解
- 需要“保存价值”的流程/权衡/对比类小红书图文

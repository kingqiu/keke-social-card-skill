关键结构

复杂任务 / PROMPTING

把会改变结果的条件，补到 Prompt 里。

4
PARTS
01 / GOAL目标

要它做什么？先从最终结果说起。

02 / CONTEXT上下文

哪些来源、资料或视觉信息会改变答案？

03 / OUTPUT输出

要什么格式、长度、层级，才能拿来就用？

04 / BOUNDARY边界

什么不能动？什么要先问，不要擅自做？

×不必每项都填

官方指南明确建议：只使用真正有帮助的部分，不需要死记格式。

→第一轮后再迭代
